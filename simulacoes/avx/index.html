Assembly escalar

x86-64 · Intel

RSI aponta para a entrada, RDI para a saída e RAX guarda o índice. Entrada e saída ocupam regiões distintas. Cada double ocupa 8 bytes. O rótulo de dados escala aponta para a constante 2,5.

Código em C

#include <stddef.h>

void multiplicar(
    double *restrict saida,
    const double *restrict entrada)
{
    const double escala = 2.5;
    for (size_t i = 0; i < 1024; ++i) {
        saida[i] = entrada[i] * escala;
    }
}

Contagem de instruções

MULSD multiplica o double na posição baixa do registrador XMM. O laço avança um índice após cada gravação.

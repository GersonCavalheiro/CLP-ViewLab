Assembly AVX

x86-64 · Intel

RSI aponta para a entrada, RDI para a saída e RAX guarda o índice. Entrada e saída ocupam regiões distintas. Cada double ocupa 8 bytes. O rótulo de dados escala aponta para a constante 2,5.

Código em C

#include <stddef.h>

void multiplicar(
    double *restrict saida,
    const double *restrict entrada)
{
    const double escala = 2.5;
    for (size_t i = 0; i < 1024; ++i) {
        saida[i] = entrada[i] * escala;
    }
}

Contagem de instruções

VBROADCASTSD copia o fator para as quatro posições de YMM1. VMULPD multiplica as posições correspondentes. Como 1024 é múltiplo de 4, o laço cobre todo o vetor.

Contamos as instruções do trecho exibido. As duas instruções iniciais executam uma vez. Cada iteração executa seis instruções, incluindo o salto condicional da última iteração. O rótulo .laco apenas marca o destino do salto.
